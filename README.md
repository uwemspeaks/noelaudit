# Noel Talents Limited Career Readiness Audit

A responsive, scenario-based career readiness assessment covering CV audit and optimization, LinkedIn optimization, and interview preparation.

## Files

- `index.html` — page structure and content
- `styles.css` — branding, layout, and responsive styles
- `app.js` — the 15 scenarios, scoring, feedback, results report, and interactions
- `logo.png` — Noel Talents Limited logo used in the header and report

## Run locally

Open `index.html` in a browser. The application runs entirely in the browser and does not require a build step or backend for the assessment itself.

## Deploy to Netlify

1. Upload these files to the root of a GitHub repository.
2. In Netlify, import that repository as a new site.
3. Leave the build command blank.
4. Set the publish directory to `.` (repository root).
5. Deploy.

The score and feedback are generated in the browser. This version does not store candidate results in a central database or automatically send candidate information to Noel Talents Limited.
